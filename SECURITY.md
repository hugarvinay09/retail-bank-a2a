# Security policy

Do not open a public issue for a suspected vulnerability or include customer data, credentials,
payment identifiers, raw prompts, or provider responses in any report. Use the bank's approved
private security reporting channel and incident process. Replace this paragraph with the client's
actual security contact and response SLA before publishing the repository.

Supported production releases receive critical security fixes. Development branches and the local
mock bank are not production services. Rotate any credential immediately if it is exposed, preserve
audit evidence, and follow the bank's incident response and regulatory notification requirements.
